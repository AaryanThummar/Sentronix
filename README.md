## 👁️‍🗨️ Executive Overview

> *"Traditional vulnerability scanners tell you that you are broken; SentroniX emulates the adversary, validates the defense, writes the patch with AI, and opens the Pull Request."*

**SentroniX Version 3.0 PRO** is an end-to-end, enterprise-grade **Purple Team AI Ecosystem**. It fuses offensive security operations (Red Team payload fuzzing, MITRE ATT&CK atomic strikes, Caldera APT campaigns) with defensive resilience (Blue Team hot-reloading WAF policy switchboards, real-time packet interception, Steg malware extraction), powered by an **autonomous Google Gemini AI Remediation Engine** that generates unified Git diffs and automated GitHub Pull Requests.

Version 3 introduces **Active Defense Browser Extension V3** (client-side DOM webmail phishing inspection and download steganography shields) alongside a **Zero-Docker Portable Standalone Engine** that runs anywhere with a single double-click.

## 🎮 Core Capabilities & Feature Bento

### 🔴 1. Red Team Adversary Simulation & Attack Launchpad
- **Atomic Red Team Integration**: Dispatch mapped MITRE ATT&CK atomic tests directly against internal assets or web applications.
- **PayloadsAllTheThings Arsenal**: Integrated vector sets for SQL Injection, DOM XSS, Blind SSRF, IDOR token tampering, and Directory Traversal.
- **MITRE Caldera APT Campaigns**: Multi-phase attack execution simulating Advanced Persistent Threat actors, evaluating containment at each operational hop.
- **Live Endpoint Fuzzer**: Dispatch high-velocity multi-probe payload bursts against custom target URLs with real-time status code, latency, and reflection telemetry.

### 🔵 2. Blue Team Dynamic WAF Policy Switchboard
- **Zero-Downtime Rule Hot-Reloading**: Toggle defensive inspection rules (`AST_SQLI_GUARD`, `WAF_XSS_INTERCEPTOR`, `SSRF_METADATA_FILTER`) instantly without server restarts.
- **Deep Packet Inspection Console**: Watch incoming raw HTTP payloads get analyzed, filtered, and neutralized in an authentic ANSI terminal stream.
- **Automated Defensive Resilience Grading**: Dynamic mathematical rating of perimeter defense based on blocked vs. bypassed probe ratios.

### 🧠 3. Autonomous Google Gemini AI Remediation Engine
- **Unified Git Patch Generation**: Generates standard syntax-highlighted Git diffs (`--- a/`, `+++ b/`) that drop in cleanly to replace vulnerable code with secure implementations.
- **Root Cause & Vulnerability Breakdown**: Provides plain-language explanations of the vulnerability mechanics and CWE taxonomy mappings.
- **Automated QA Verification Checklist**: Step-by-step developer checklists to verify that the patch eliminates the vulnerability without regressing functional logic.

### 🐙 4. One-Click GitHub Pull Request Automation
- **Remote Branch Staging**: Creates dedicated remote Git branches (`sentronix/remediation-...`) directly from the browser UI.
- **Automated Pull Request Submission**: Opens formatted GitHub Pull Requests with title, description, code diff, and CWE references in a single click.

### 🌐 5. SentroniX Active Defense Browser Extension V3
- **Webmail DOM Inspector**: Scans email content in real time across **Gmail** and **Outlook Webmail**, tagging suspicious hyperlinks with visual threat badges.
- **Real-Time Typosquatting Interception**: Detects homograph attacks, suspicious TLDs (`.xyz`, `.top`), and brand impersonation before users click.
- **Stego Download Interceptor**: Hooks browser download streams to inspect images and attachments for hidden executable payloads or LSB steganography before they hit disk.
- **Light Bento UI & Purple Emoji Logo**: Polished user interface featuring real-time protection shields, a Quick URL Analyzer, and live telemetry cards.

### 📊 6. Executive Compliance & CISO Audit Suite
- **Continuous Compliance Readiness**: Real-time meters for **SOC 2 Type II**, **ISO 27001**, and **OWASP Top 10**.
- **Formal PDF Audit Generation**: Export branded security assessment reports (`REP-2026-003`) complete with threat matrices, executive summaries, and CISO sign-off signature blocks.

### 🚀 7. Zero-Docker Portable Standalone Deployment
- **No Docker Required**: Run the complete platform with a single click using `run_sentronix_standalone.bat` (Windows) or `run_sentronix_standalone.sh` (Linux/macOS).
- **Embedded SQLite Engine**: Auto-initializes `sentronix.db` with zero database installation or configuration hassle.
- **Single-Port Architecture**: Serves both the compiled React Single Page Application and FastAPI REST endpoints together on port `8000`.

## ⚡ Quick Start & Deployment

For complete, detailed instructions, consult the **[Installation & Deployment Manual](INSTALL.md)**.

### Option A: Docker Compose (Production Microservices)
```bash
# 1. Clone the repository
git clone https://github.com/AaryanThummar/Sentronix.git
cd Sentronix/sentronix-platform

# 2. Build and run all 5 microservices in detached mode
docker compose up -d --build

# 3. Access Web Dashboard
# -> Frontend:  http://localhost:5173
# -> API Docs:  http://localhost:8000/docs
```

### Option B: Zero-Docker Portable Standalone (1-Click)
```cmd
# Windows (Double-click or run from CMD):
run_sentronix_standalone.bat

# Linux / macOS:
chmod +x run_sentronix_standalone.sh
./run_sentronix_standalone.sh

# -> Access Unified Dashboard & API at: http://localhost:8000
```

### Option C: Browser Extension V3 Installation
1. Open Chrome/Edge and go to `chrome://extensions`.
2. Toggle **Developer mode** to **ON** (top right).
3. Click **Load unpacked** and select `sentronix-platform/browser-extension`.
4. Pin the purple shield extension to your browser toolbar!
